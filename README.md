# Avatar Fork
A toolset that can be used to create custom versions of avatars.

The tool can be found it Unity at: ``TohruTheDragon/AvatarFork``

## Bone Remapper
You can try to fix your avatar with this tool, if the mesh exploded, after you overwrite the FBX outside of Unity
<img src="https://github.com/fkrisi11/AvatarFork/blob/main/Media/Bone%20Remapper.jpg?raw=true" />

## Copy Controller
Copy entire controllers, with all animations also duplicated, and reassigned to the controller<br>
<img src="https://github.com/fkrisi11/AvatarFork/blob/main/Media/Copy%20Controller.jpg?raw=true" />

## Copy Expression
Make a unique copy of an avatar's entire menu (and parameter list), along with the icons<br>
Find menu items without icons, and with icons that have already been used elsewhere in a menu
<div>
  <img src="https://github.com/fkrisi11/AvatarFork/blob/main/Media/Copy%20Expression%20Copy.jpg?raw=true" Width="400" />
  <img src="https://github.com/fkrisi11/AvatarFork/blob/main/Media/Copy%20Expression%20Analysis.jpg?raw=true" Width="400" />
</div>

## Copy Material
Copy the materials used by the avatar, along with the textures if needed, which are then reassigned in the materials
<img src="https://github.com/fkrisi11/AvatarFork/blob/main/Media/Copy%20Material.jpg?raw=true" />

## Dynamics Organizer
Take all dynamics (physbones, physbone colliders, contacts) from the armature, and put them at the avatar's root<br>
Or copy all dynamics to another copy of the same avatar, no matter if the dynamics are in the armature or not<br>
Note: The second image shows the prepare screen just before the copy. There is a second avatar selection screen before
<div>
  <img src="https://github.com/fkrisi11/AvatarFork/blob/main/Media/Dynamics%20Organizer%20Organize.jpg?raw=true" Width="400" />
  <img src="https://github.com/fkrisi11/AvatarFork/blob/main/Media/Dynamics%20Organizer%20Copy.jpg?raw=true" Width="400" />
</div>

## Parameter Organizer
Organize your animator parameters easier, with multi-select, drag and drop, and other sorting methods
<img src="https://github.com/fkrisi11/AvatarFork/blob/main/Media/Parameter%20Organizer.jpg?raw=true" />

## WD Off Reset Helper
Find all blendshapes, that are only animated in your reset animation, and all blendshapes that are not animated in the reset animation
<img src="https://github.com/fkrisi11/AvatarFork/blob/main/Media/WD%20Off%20Reset%20Helper%20Cleanup.jpg?raw=true" />
<img src="https://github.com/fkrisi11/AvatarFork/blob/main/Media/WD%20Off%20Reset%20Helper%20Sync.jpg?raw=true" />
